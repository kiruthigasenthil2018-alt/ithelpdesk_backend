# Slow Computer, Freezing and Blue Screen Errors
## Slow computer
Restart the laptop at least once a week. Close programs you are not using and disable unnecessary startup apps in Task Manager. Make sure at least 15 percent of the disk is free. Install pending Windows updates.
## Application not responding
Wait a minute, then end the task in Task Manager. Reopen the program. If it keeps happening, clear its cache or repair it from Settings.
## Blue screen (BSOD)
Write down the stop code shown on the screen, for example MEMORY_MANAGEMENT. Restart the computer. If it happens again, disconnect external devices, install updates and raise a hardware ticket with the stop code.
## Computer will not start
Hold the power button for 15 seconds, check the charger and try again. If the screen stays black, raise a hardware ticket.
