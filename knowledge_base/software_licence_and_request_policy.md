# Software Licence and Request Policy
Only approved software may be installed on company laptops. Request new software through the service catalog and include the business reason.
Approval flow: your manager approves the need, then IT checks security and licence cost, then the software is delivered through the software center.
Licence not found or expired: sign out and sign in with your work account. If the message continues, raise a ticket naming the application.
Free and open-source tools still need approval. Never use cracked or pirated software; it is a security risk and a policy violation.
Removing software: raise a request. Users cannot uninstall security tools.
